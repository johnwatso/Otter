# Security policy

## Supported releases

Security fixes are made for the latest public Otter release. Please update to
that release before reporting an issue when practical.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, credential exposure,
or a way to access a share without authorization. Instead, use GitHub's
[private vulnerability reporting form](https://github.com/johnwatso/Otter/security/advisories/new).

Include a clear description, affected Otter and macOS versions, reproduction
steps, expected and actual behavior, and any suggested mitigation. Remove
passwords, recovery keys, session tokens, private server addresses, and
unredacted diagnostics.

We will acknowledge a valid report, investigate it privately, and coordinate
disclosure and a fix with the reporter where possible.
