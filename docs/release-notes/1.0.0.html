Otter 1.0 🦦

Version 1.0.0 · Build 2026101901 · Released 19 October 2026

Otter 1.0 is here. It keeps your SMB shares mounted through sleep, network changes, VPN reconnects and server restarts, and now it looks and feels the part: a redesigned Manage Shares window, a guided first run, and a much clearer picture of how reliable each share really is.

✨ A redesigned Manage Shares window

  • A new status header, a Reliability strip, Connection Details and Connection Behavior cards, and a sidebar that groups shares under their server with status indicators lined up on the trailing edge.
  • Give any share or server its own icon, and see your chosen share icons in the menu bar too.
  • Icon-only Finder, disconnect and pause controls keep the header calm, and the menu bar menu is simpler.

🚀 A guided first run

  • A four-step onboarding walks you from a server address to a mounted share, connecting through the standard macOS sign-in so your password never goes in a share URL.
  • Otter can offer to manage a share you mount in Finder, and cleans up the duplicate connections that aliases such as nas.local create.
  • Otter 1.0 supports SMB shares. NFS and WebDAV are not supported yet.

🔌 Smarter connections

  • Open an SMB share in Finder while away from your home network and Otter connects the VPN for you, mounts the share, and tells you when it is ready.
  • Optional fallback addresses and Wake-on-LAN-aware behaviour help shares recover when a server is asleep or its name does not resolve.

📈 Reliability you can see

  • A seven-day Reliability card shows daily health and response times for each share and for the whole server.
  • Response time is now measured as a real TCP round trip, so the numbers reflect the connection rather than how long a health check took.

🩺 Diagnostics that explain what is wrong

  • A redesigned Diagnose sheet runs per-share NAS checks, including a quick speed test, and diagnostic runs no longer hang.
  • A redesigned Activity Log makes it easy to see what Otter did and when.
  • Export a readable diagnostic report with identifying details removed.

⚙️ Tidier Settings

  • Wi-Fi and VPN status and the backup and restore actions are always visible instead of tucked behind disclosures and menus, in a compact, fixed-size window.
  • Notifications now live in General, and Settings has fewer, clearer options.

🔒 Built for a 1.0

  • A privacy manifest, Swift 6 concurrency, and accessibility and destructive-action improvements throughout.
  • Requires macOS 15 or later, and is designed for macOS Tahoe.
