Otter Release Notes

Recent updates for Otter on macOS

🦦 Version 1.0.0

  • Redesigns Manage Shares with a status header, Reliability strip, detail cards and custom share and server icons.
  • Adds a guided four-step first run that connects through the standard macOS sign-in.
  • Connects your VPN and mounts the share when you open an SMB share in Finder away from home.
  • Shows seven days of reliability and measures response time as a real TCP round trip.
  • Redesigns the Diagnose sheet and Activity Log, and tidies Settings.
  • Updates Otter to version 1.0.0 build 2026101901.

🩺 Version 0.5.0

  • Adds a read-only NAS Diagnostics panel to every share and server, covering health, routing, SMB channels and latency.
  • Adds an optional 1–5 GB speed test with Compare After Reconnect and Compare Using IP Address, restoring your connection afterwards.
  • Adds Copy Diagnostic Report, which leaves out credentials and Keychain contents.
  • Updates Otter to version 0.5.0 build 2026090711.

🏠 Version 0.4.2

  • Prefers a directly reachable local server before starting or waiting for a VPN.
  • Manual share disconnects no longer create automatic-mount pauses, and labels distinguish Manual shares from automatic ones.
  • Adds an Always Show Server Name preference.
  • Updates Otter to version 0.4.2 build 2026083109.

🛟 Version 0.4.1

  • Keeps Otter running in the menu bar after every window is closed, so the share monitor keeps working.
  • Updates Otter to version 0.4.1 build 2026083108.

🧹 Version 0.4.0

  • Adds connection modes so each share is kept connected, connected adaptively, mounted once, or left to you.
  • Cleans up the duplicate server entries Finder shows when a share is mounted through an alias of its name, and unmounts redundant copies of a share.
  • Fixes Keychain lookups that hid saved connections and reported missing credentials for servers that had them.
  • Retries an unexpected disconnect faster and keeps several fallback addresses per share.
  • Schedules when a downloaded update installs.
  • Updates Otter to version 0.4.0 build 2026082816.

🧭 Version 0.3.0

  • Guided SMB setup now includes a clear Permissions step, discovers mounted and saved shares, browses servers, and checks readiness before saving.
  • Adds Wake-on-LAN, mounted-volume health checks, hostname IP fallback, and clearer recovery tools.
  • Keeps the Dock visible during editing and Preferences, adds the standard ⌘, shortcut, and expands Shortcuts support.
  • Introduces protected configuration transfer and managed deployment support.
  • Updates Otter to version 0.3.0 build 2026081414.

🔧 Version 0.2.0

  • 👀 Adds a durable offer to manage newly mounted Finder shares, with more reliable event handling and editor presentation.
  • 🔒 Adds manual VPN mode and lets a share use its local network or configured VPN path.
  • 🔔 Improves notification delivery and the published Sparkle update-feed paths.
  • Updates Otter to version 0.2.0 build 2.

🌎 Version 0.1.0

  • 📁 First public release: native SMB share monitoring and reconnection for macOS.
  • 🧭 Introduces guided setup, VPN-aware rules, Wake-on-LAN, diagnostics, and Shortcuts support.
  • 🍎 Adds configuration transfer, managed deployment, automatic updates, and the GitHub Pages website.
  • Updates Otter to version 0.1.0 build 1.
