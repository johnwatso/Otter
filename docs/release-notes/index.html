Otter Release Notes

Recent updates for Otter on macOS

🧭 Version 0.3.0

  • Guided SMB setup now includes a clear Permissions step, discovers mounted and saved shares, browses servers, and checks readiness before saving.
  • Adds Wake-on-LAN, mounted-volume health checks, hostname IP fallback, and clearer recovery tools.
  • Keeps the Dock visible during editing and Preferences, adds the standard ⌘, shortcut, and expands Shortcuts support.
  • Introduces protected configuration transfer and managed deployment support.
  • Updates Otter to version 0.3.0 build 2026081414.

🔧 Version 0.2.0

  • 👀 Adds a durable offer to manage newly mounted Finder shares, with more reliable event handling and editor presentation.
  • 🔒 Adds manual VPN mode and lets a share use its local network or configured VPN path.
  • 🔔 Improves notification delivery and the published Sparkle update-feed paths.
  • Updates Otter to version 0.2.0 build 2.

🌎 Version 0.1.0

  • 📁 First public release: native SMB share monitoring and reconnection for macOS.
  • 🧭 Introduces guided setup, VPN-aware rules, Wake-on-LAN, diagnostics, and Shortcuts support.
  • 🍎 Adds configuration transfer, managed deployment, automatic updates, and the GitHub Pages website.
  • Updates Otter to version 0.1.0 build 1.
