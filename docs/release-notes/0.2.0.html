Otter 0.2.0

Version 0.2.0 · Build 2

A reliability-focused release that makes it easier to bring existing shares into Otter and safer to respond when a new one appears.

👀 Manage newly mounted shares

Otter can now notice a Finder-mounted share and offer to take care of it for you.

  • Detects new mounted shares and offers to add them to Otter.
  • Keeps the offer available in the menu bar until it is answered, rather than losing it with a notification.
  • Coalesces rapid mount and unmount events so a new share is not silently missed.
  • Waits for Manage Shares to be ready before opening the prefilled editor.

🔒 More flexible VPN paths

A share can now use the most appropriate route without being overly strict about the path you are currently on.

  • Adds a manual VPN connection mode alongside automatic connection.
  • Lets a share connect from its registered local network or through its configured VPN path.
  • Improves the VPN state surfaced in the menu bar, setup screens, and connection guidance.

🔔 Quieter, more dependable notifications

The app now works with macOS’s notification model rather than asking for a delivery mode it cannot use.

  • Uses standard persistent notification delivery for new-share offers.
  • Delivers workspace notifications on the posting thread so scanning remains correctly scheduled.
  • Updates the website and Sparkle update-feed deployment to serve release information from the right paths.
