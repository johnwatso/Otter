Otter 0.4.1

Version 0.4.1 · Build 2026083108 · Released 31 August 2026

A small maintenance release that keeps Otter quietly watching your shares even when every window is closed.

🛟 Always on in the menu bar

Closing a window is no longer mistaken for quitting the app.

  • Otter stays running after you close Manage Shares, Preferences, or the last other window, so the share monitor keeps working in the background.
  • macOS automatic termination is switched off from the moment Otter launches, because an idle share monitor still has work to do.
  • Choosing Quit still quits, as you would expect.
