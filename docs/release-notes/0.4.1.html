Release Otter 0.4.1

Otter 0.4.1 (build 2026083108) is a maintenance release that keeps the menu bar app and its share monitor running when no Otter windows are open.

Background reliability
- Keeps Otter alive after Manage Shares, Preferences, or the last other app window is closed, so closing a window is no longer mistaken for quitting the app.
- Explicitly disables AppKit automatic termination at launch because an idle share monitor still has background work to perform.
- Sets NSSupportsAutomaticTermination to false in the application metadata, making the resident-agent behavior consistent from the moment macOS launches Otter.
- Preserves normal explicit Quit behavior and sudden termination support.

Release metadata
- Bumps the app marketing version from 0.4.0 to 0.4.1.
- Advances the build number from 2026082816 to 2026083108 in both Debug and Release configurations.

Verification
- Validated Otter/Info.plist with plutil.
- Confirmed Xcode resolves MARKETING_VERSION 0.4.1 and CURRENT_PROJECT_VERSION 2026083108.
- Ran the complete Otter test suite: 167 tests passed with zero failures.
