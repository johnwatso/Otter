Version 0.5.0

Add per-share NAS diagnostics

Release notes:
- Add a NAS Diagnostics panel to every share and server detail panel in Manage Shares, reporting connection health, routing, SMB dialect and channels, and latency from a read-only check.
- Report an expected practical maximum from verified active SMB channels, capped by each client interface, so utilisation is measured against a defensible ceiling rather than a nominal link speed.
- Add an optional 1-5 GB share performance test that writes and reads a temporary file in its own uniquely named folder, requests client cache bypass, and removes what it created on success and on cancellation.
- Add Compare After Reconnect and Compare Using IP Address, which repeat diagnostics and any matched performance test, then restore the configured connection including after failure or cancellation.
- Offer Restore Configured Connection when a temporary direct-IP mount cannot be verified, leaving saved addresses, credentials, and connection rules unchanged throughout.
- Report cautious findings with good, informational, and warning severities, and never treat an unavailable measurement as zero or as proof that nothing is wrong.
- Add Copy Diagnostic Report, which exports selected fields rather than raw command output and excludes credentials, Keychain contents, and unrelated SMB sessions.
- Leave busy shares mounted rather than forcing an unmount, and give every diagnostic subprocess a deadline so a stalled NAS cannot hold a check open.
- Bump Otter to version 0.5.0 (build 2026090711).
- Add regression coverage for health and efficiency thresholds, channel capacity caps, Wi-Fi awareness, session and wake context, comparison restoration after failure and cancellation, report field selection, subprocess deadlines, and temporary-file cleanup.
