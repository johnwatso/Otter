Otter 0.5.0

Version 0.5.0 · Build 2026090711 · Released 7 September 2026

Otter can now tell you why a share is slow. Every share and server gets a read-only NAS Diagnostics panel, with an optional speed test.

🩺 NAS Diagnostics

Connection health, routing and speed in one place.

  • A new panel in every share and server detail view reports connection health, routing, SMB dialect and channels, and latency from a read-only check.
  • Utilisation is measured against an expected practical maximum, based on verified active SMB channels and capped by each client interface, rather than a nominal link speed.
  • Findings are marked good, informational or warning. An unavailable measurement is never treated as zero or as proof that nothing is wrong.

🚀 Performance test

Measure real throughput without leaving a mess behind.

  • An optional 1–5 GB test writes and reads a temporary file in its own uniquely named folder, asks the client to bypass its cache, and cleans up on success and on cancellation.
  • Compare After Reconnect and Compare Using IP Address repeat the diagnostics and any matched speed test, then restore your configured connection, even after a failure or cancellation.
  • If a temporary direct-IP mount cannot be verified, Restore Configured Connection puts everything back. Saved addresses, credentials and connection rules are never changed.

🔒 Safe by design

Diagnostics never get in the way of your shares.

  • Copy Diagnostic Report exports selected fields rather than raw command output, and leaves out credentials, Keychain contents and unrelated SMB sessions.
  • Busy shares stay mounted instead of being forced off, and every diagnostic subprocess has a deadline so a stalled NAS cannot hold a check open.
