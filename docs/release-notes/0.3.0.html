Otter 0.3.0

Version 0.3.0 · Build 2026081414

A more capable, more guided Otter: setup is easier, recovery is clearer, and the menu bar app behaves more like a polished macOS citizen when you need it.

🧭 Guided share setup

Bring existing and new network shares under Otter’s care with less manual entry.

  • Discover mounted shares, nearby SMB servers, and saved Finder SMB connections while adding a share.
  • Browse a server’s available shares using macOS’s native authentication and selection flow.
  • Run a Connection Readiness check before saving to catch network, VPN, credential, and service problems early.
  • Offer to manage shares mounted outside Otter, with the suggestion preserved until you answer it.
  • Choose Local Network discovery, notifications, and optional Wi-Fi-name access from a clear Permissions step before setup begins.

🔌 Stronger connection recovery

Otter has more ways to keep an important share available without becoming noisy.

  • Adds Wake-on-LAN support for sleeping servers.
  • Checks mounted-volume health, including responsiveness, write access, and an optional expected file.
  • Learns a local IP address for hostname-based shares and uses it as a fallback when name resolution is unavailable.
  • Improves VPN-aware connection handling, manual VPN control, credential recovery, and reliability reporting.

⚙️ Better macOS fit

Small interface details make Otter easier to reach without giving up its lightweight menu-bar nature.

  • The Dock icon appears while editing a share or using Preferences, regardless of the selected app-presence mode.
  • ⌘, now opens Preferences.
  • The About panel includes the Otter website and a small Made in NZ credit.
  • Expands Shortcuts support for mounting, pausing, checking status, reviewing reliability, and recovering credentials.

🔒 Safer configuration management

Move and manage configuration with clearer boundaries around credentials and device policy.

  • Adds versioned configuration transfer with protected backups for eligible SMB credentials.
  • Supports managed deployment controls for shared policies and monitoring settings.
  • Keeps learned fallback addresses out of exported configuration and redacts them from diagnostics.
