Improve share controls and direct connectivity fallback

Release notes:
- Prefer a directly reachable local server before starting or waiting for a configured VPN in Manual, Adaptive, and Connect Once modes.
- Preserve explicit registered-network restrictions while treating VPN-only configuration as a fallback connection path.
- Make Manual share disconnect actions avoid creating automatic-mount pauses, and hide pause controls when no automatic shares are present.
- Update menu bar and Preferences labels so disconnect behavior clearly distinguishes Manual shares from automatically maintained shares.
- Add an Always Show Server Name preference and singular/plural share-count labels for menu organization.
- Bump Otter to version 0.4.2 (build 2026083109).
- Add regression coverage for local-first VPN routing, Manual disconnect behavior, pause state, server grouping, and preference persistence.
